# VAULTBREAK: Museum of Night

[![make.fun best-heist-game](https://img.shields.io/badge/make.fun-best--heist--game-20261122--0559-orange)](https://make.fun/bounty/best-heist-game-20261122-0559)

An original top-down heist game. Sneak through the Museum of Night, dodge guard vision cones and sweeping cameras, loot exhibits and crack the main vault, then escape to the getaway van.

Play: open `game/index.html` via a static server. WASD / arrows move, Shift sneaks, click throws a coin to distract guards, E drops a smoke bomb.

Referral: https://make.fun/r/vwpycztt

Competition: https://make.fun/bounty/best-heist-game-20261122-0559

Run the hand-in program: `MAKEFUN_OUTPUT_DIR=out node main.ts`
