An original top-down heist game in plain static files. Cross a night museum as the thief: read the guards' patrols and vision cones, dodge the sweeping cameras, keep the alarm meter down, grab the loot and the $500 vault, then reach the getaway van. Two entries (main door and vent), coin tosses and smoke bombs as limited tools.

Open `game/index.html` in a desktop browser and play with keyboard and mouse. No build step, no network.
